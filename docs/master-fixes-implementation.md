# Master fixes implementation — 14 October 2026

This records the implementation requested in `YRDLY_Codex_Master_Fixes.md`. It makes no claim of manual or automated flow testing; manual testing remains with the owner.

| Issue | Root cause and implementation | Main files / limitations |
| --- | --- | --- |
| 1. Feed media and post detail | Fixed-height web wrappers clipped natural media. Shared web media now follows each image/video's dimensions and includes all video attachments; mobile measures available width and intrinsic aspect ratios. Account-scoped feed/post snapshots preserve content, engagement and return position; players pause when hidden or unfocused. | Web `PostCard`, `PostDetailView`, `HomeScreen`, `client-feed-state`; mobile `PostCard`, `posts/[id]`, `post-memory`. Extreme mobile feed previews have bounded aspect ratios; expanded views use natural dimensions. |
| 2. Nearby user rows | `DiscoverUserCard` used a filled glass card. Rows now use the surrounding surface with subtle separators. | Mobile `DiscoverUserCard`. Existing filter/input backgrounds are retained. |
| 3. Business pictures | Some businesses have their uploaded images in `image_urls`, while Explore only checked logo/cover fields. Cards now include that real image source. Public production media requests examined during diagnosis succeeded; missing files were not established as the general cause of missing avatars. | Mobile `catalog`; web public-storage host allowlist in `next.config.mjs`. No bucket was made public to hide permission failures. |
| 4. Marketplace overlays | Theme-dependent dark text/icons had poor contrast over images, and the heart was not an action. Badges use opaque backgrounds and clear text; the heart reflects the existing favorite RPC and prevents repeat submissions. Removed the excessive Explore event-image dark overlay. | Mobile `catalog`, `MarketplaceFavorite`. |
| 5. SQLite persistence | Previous JSON caches were not reliably account-scoped. Added encrypted, versioned SQLite with parameterized operations, generation guards, metadata cache, profile snapshot, post drafts and pending outbox. Cached listings/feed are explicitly labelled and revalidated. | Mobile `local-cache`, `use-cached-records`, `use-posts`, `create-post`, auth provider. A native rebuild is required; media remains file-based, and original temporary files can be removed by the OS. |
| 6. One active session | Valid older JWTs continued to authorize requests. New logins establish ownership in the backend; RLS, write guards, API and Edge Function checks enforce it. Foreground/reconnect checks clear account state and explain revocation. Native Supabase single-session configuration complements this guard. | Migration `20261014164602`, web/mobile `session-policy`, server auth helper, OTP/moderation Edge Functions. Requires coordinated backend deployment; existing accounts keep their newest session at cutover. |
| 7. Comments header | The current bottom-sheet header already shares the sheet background and has no separate grey title fill. Preserved it. Removed redundant client counter writes: existing database triggers own persisted comment counts. | Mobile `CommentsBottomSheet`, `posts/[id]`. Drag handle, keyboard behavior and composer remain. |
| 8. Community approval | Membership queries could treat pending/rejected communities as active. My Communities now requires approved status; direct access and related content are guarded in the database. Review history is collapsed and uses existing dismissal records. | Mobile `community-service`, `CommunitiesContent`; migration `20261014164602`. Moderation records are preserved. |
| 9. Rich share links | Public routes were client pages and associations used obsolete/placeholder identities. Server metadata now selects only eligible public records; native share text includes canonical URLs. Association routes use actual release identity configuration. | `public-link-metadata`, server page wrappers, `.well-known` route handlers, `next.config.mjs`. Android certificate configuration uses EAS metadata. `APPLE_TEAM_ID` must come from the owner's signing team; App Links require a Play signing certificate too when that signing identity differs. Preview providers decide their final presentation. |
| 10. Inline Communities | Discover navigated away to a separate community screen. Reused the existing functionality as an inline state, retaining Explore/navigation; rows and cache merges deduplicate by community ID. | Mobile `DiscoverPeopleSection`, `CommunitiesContent`, `community-service`. Dedicated detail/create/moderation routes remain. |
| 11. Messages and uploads | Sends waited for inserts and blocking notification work; inserts were conflated with delivery. Messages now appear as sending, reconcile by stable UUID, retain failures and retry idempotently. Recipient acknowledgements distinguish delivery/read; histories paginate and reconnect refreshes. Uploads use native binary transfers, bounded concurrency, real transport progress and cancellation where wired, with sensible image dimensions. | Mobile/web chat screens, storage services, mobile `use-posts`; migration `20261014172816`. Legacy `business_messages` lacks a recipient/conversation key and is excluded from individual web chats rather than mixing buyers. Uploads are not universally resumable/background transfers, and no measured speedup is claimed. |
| 12. Simple editors | Existing controls relied on numeric ratios and directional buttons. Added visual freeform crop handles, explicit presets, pan/pinch framing, and asynchronous thumbnail strips with dual trim handles. Confirm uses real native/browser export; cancellation retains originals and discards owned intermediate files. | Web `CropSelection`, `ImageCropDialog`, `VideoEditDialog`, `VideoTrimTimeline`; mobile `CropFrame`, `ImageEditModal`, `VideoEditModal`, `VideoTrimTimeline`, `use-image-editor`. Native video export may re-encode; browser export depends on available codecs and remains bounded by upload limits. |

Deployment dependencies: apply the two migrations before deploying clients that require the session/receipt RPCs; deploy the affected OTP and moderation Edge Functions; rebuild Android/iOS for the SQLite native plugin. The owner handles the IPA and manual usability checks. Map keys, payment provider configuration and financial records are outside this batch.

Association environment variables contain public signing identifiers: `ANDROID_APP_LINK_SHA256_FINGERPRINTS` is a comma-separated list of SHA-256 certificate fingerprints; `APPLE_TEAM_ID` is the ten-character Apple Developer Team ID for `com.yrdly`. Missing identifiers produce empty associations rather than invented ones.
