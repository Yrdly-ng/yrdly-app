# Bundled YRDLY brand fonts

These Latin WOFF2 variable fonts preserve the typography used by the YRDLY app while avoiding a runtime dependency on Google Fonts.

| Role | Family | File | Weights |
|---|---|---|---|
| Display / headings | Bricolage Grotesque | `bricolage-grotesque.woff2` | 200–800 |
| Body / interface | Figtree | `figtree.woff2` | 300–900 |
| Wordmark | Unbounded | `unbounded.woff2` | 200–900 |
